Fetch robot link meshes (15 STL files in this directory)

These files are copied verbatim, unmodified, from the Gymnasium-Robotics Python package
(gymnasium-robotics 1.4.2, Farama Foundation), path gymnasium_robotics/envs/assets/stls/fetch/.
They are the mesh assets named by the Fetch MJCF the package ships
(gymnasium_robotics/envs/assets/fetch/shared.xml and robot.xml), which is the unmodified scene
FetchPickAndPlace-v4 simulates in this project. Only the files a geom in robot.xml uses are here;
the wheel and bellows meshes are not.
